# 🎯 Guess the Secret Number

An interactive number guessing game built using **HTML, CSS, and JavaScript** as part of my JavaScript learning journey.

## 🎮 About the Project

The computer generates a random number between 1 and 100, and the player has five attempts to guess the correct number.

The game provides hints after each guess, helping players narrow down the secret number.

## ✨ Features

- Random number generation
- Interactive user input
- Too High / Too Low hints
- Five-attempt limit
- Input validation
- Win and Game Over messages
- Play Again functionality
- Responsive design with colorful styling

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity

## 🧠 JavaScript Concepts Practiced

- Functions and return statements
- Variables and conditional statements
- `Math.random()` and `Math.floor()`
- DOM manipulation
- Event handling using `onclick`
- Type conversion using `Number()`
- Input validation
- Debugging using Chrome Developer Tools
